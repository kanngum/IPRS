Before importing

  • The JSON root must be an array of programme objects.
  • Each record must have a unique, non-empty ID, title and institution.
  • Invalid files are rejected before the catalogue is saved.
  • Export a backup before replacing important data.
  • Mark a programme as verified only after checking its official source.
